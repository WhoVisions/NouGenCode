# ⚡ Edge Face Geometry & Landmark Analyzer

## Overview
Extracts strict mathematical facial schemas (identity vectors, eye-to-nose-to-chin ratios, jawline angles, expression weights, and skin texture heuristics) for identity preservation and rendering.

## Included Modules
- `face_math.py`: JSON schema extractor for geometric landmark ratios.
- `facial_analyzer.py`: Landmark alignment and visual feature profiling.
- `skin_analyzer.py`: Texture sampling and tone heuristics.
- `spatial_analyzer.py`: 3D bounding geometry and spatial orientation.
