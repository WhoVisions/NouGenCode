# ⚡ Edge Media Graph Clients

## Overview
High-performance REST and GraphQL API clients for querying structured media entity databases, characters, relations, and metadata.

## Included Clients
- `anidb_client.py`: XML/HTTP client for AniDB metadata.
- `anilist_client.py`: GraphQL queries for character and series graph nodes.
- `jikan_client.py`: REST client for MyAnimeList open API data.
