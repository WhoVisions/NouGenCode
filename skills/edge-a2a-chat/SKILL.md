# ⚡ Edge Agent-to-Agent (A2A) Protocol

## Overview
Provides low-latency socket-based direct inter-agent messaging, conversational turn-taking, and context clamping between peer terminals.

## Key Primitives
- Socket-based message dispatch
- Dynamic context limit estimation
- Grounding snippet injection
