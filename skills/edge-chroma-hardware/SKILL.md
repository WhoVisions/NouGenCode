# ⚡ Edge Chroma Hardware Controller

## Overview
Connects to local hardware lighting SDKs (keyboard, mouse, headset, ChromaLink) to drive real-time physical status indicators for coding tasks, builds, and test runs.

## Supported Effects
- Static, Wave, Spectrum Cycling, Breathing, Reactive, Blinking
- Custom per-key RGB matrices for test pass/fail signals
